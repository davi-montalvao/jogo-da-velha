# 🎮 Jogo da Velha

Jogo da velha moderno e responsivo, construído com Next.js, TypeScript e CSS3, com animações suaves e suporte a modo escuro automático.

🔗 Demo: [jogo-da-velha-nu-olive.vercel.app](https://jogo-da-velha-nu-olive.vercel.app)

## ✨ Características

Interface com gradientes e sombras, totalmente responsivo para mobile e desktop, indicador do jogador atual e mensagens de vitória/empate com animações.

## 🚀 Tecnologias utilizadas

Next.js, TypeScript, CSS3 e React Hooks.

## 🎲 Como executar o projeto

```bash
git clone https://github.com/davi-montalvao/jogo-da-velha.git
cd jogo-da-velha
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador.
